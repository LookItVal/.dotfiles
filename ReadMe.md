## Installation
Simply run `sudo ./init.sh` to install. That's all you really want to know right?

Everything else below is just a description of what this is actually doing.

### init.sh
The first thing that is does is detect the OS from the small handful of specific use cases I am planning for. Right now I the old version of the dotfiles that I am basing this off of is a strange conglomerate of my OSX setup and my brothers setup. Now I mostly use ubuntu at work and will build a case for that, as well as likely my OSX setup and a possible future ARCH setup, and I want them all too look and function nearly the same.  
As of right now it only detects mac vs Linux effectively and can *likely* find what specific Linux distro you are using.
